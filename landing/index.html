Investigations that ask first.

CyberTrace turns one link into a documented evidence request: a plain-language consent screen, one button per item, and a refusal that is recorded instead of argued with.

Consent before capture

The page states who is collecting and why. Camera, microphone and location are only requested after the recipient taps their own button — never on load, never batched.

Refusals are first-class

Declining an item writes a denied record and moves on. The prompt is never shown twice, and a denial never blocks the remaining steps.

Evidence that survives

Each granted item uploads the moment it exists, so a closed tab costs you one step — not the whole session. Media lands in a private bucket behind signed URLs.

Live dashboard

Visits and captures stream into the Android app over Realtime, with filters, a map view for coordinates, and a one-tap ZIP export per link and date range.

Authorized use only. CyberTrace is for investigations you are legally permitted to run — red-team engagements, fraud cases, or your own accounts. You are responsible for the consent, disclosure and retention rules that apply where you operate. It cannot and does not read browser history, install software, or capture anything a browser permission prompt hasn't approved.

Recipients see the consent screen before anything is requested. No trackers, no third-party cookies.
